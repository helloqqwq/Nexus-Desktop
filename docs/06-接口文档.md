# Nexus 接口文档

> 本文档描述前端（`app/web`）与 Python 后端（`app/ui.py`、`app/core`）之间的本地接口。  
> 接口通过 pywebview 的 JS API 暴露，不是 HTTP 服务；只在 Nexus 自己的 WebView2 窗口内可用。

## 1. 调用方式

前端：

```js
const res = await window.pywebview.api.send({ text: '你好' });
```

统一约定：

- 所有方法返回一个 JSON 对象；成功包含 `ok: true`，失败包含 `ok: false` 和 `error`。
- 字符串参数均为 UTF-8。
- 长任务（发送消息、截图）不会阻塞调用线程；结果通过事件推送。
- 事件由 Python 主动调用：

```js
window.Nexus.onEvent(payload)
```

前端已封装 `Nexus.onEvent`，业务代码不需要直接处理 `evaluate_js`。

## 2. 方法列表

### 2.1 状态与对话

| 方法 | 参数 | 返回 | 说明 |
| --- | --- | --- | --- |
| `get_state()` | 无 | `{ok, version, has_key, mode, assistant_name, output_dir, data_dir, theme, accent, language, profile, hotkey, scenes, settings}` | 获取启动状态、场景、设置；`profile` 含 `avatar` 与 `avatar_data` |
| `send(payload)` | `{text, attachments?, session_id?}` | `{ok, session_id}` 或 `{ok:false,error}` | 发送消息；图片附件 `{type:'image', data}`（base64），文本附件 `{type:'file', name, text}` |
| `stop()` | 无 | `{ok}` | 停止当前回答 |
| `confirm_reply(payload)` | `{id, allow}` | `{ok}` | 回复确认请求；`id` 来自 `confirm_request` |
| `ask_reply(payload)` | `{id, answer?, cancelled?}` | `{ok}` | 回复提问请求；`id` 来自 `ask_request` |
| `schedule_list()` | 无 | `{ok, items}` | 列出定时任务 |
| `schedule_delete(payload)` | `{id}` | `{ok}` | 删除定时任务 |
| `schedule_toggle(payload)` | `{id, enabled}` | `{ok}` | 启用/暂停定时任务 |
| `settings_get()` | 无 | `settings` 对象 | 读取设置 |
| `settings_save(patch)` | 见 §3 | `{ok}` / `{ok:false,error}` | 保存设置并广播 `settings_changed` |
| `test_llm(payload?)` | 可选 `{base_url, model, api_key}` | `{ok, text}` / `{ok:false,error,hint}` | 用表单当前值发一条“连接测试”请求；传入的 Key 只用于本次测试，不落盘 |
| `pick_folder()` | 无 | `{ok, path}` | 打开系统文件夹选择框 |
| `pick_files()` | 无 | `{ok, paths[]}` / `{ok:false, cancelled?:true}` | 打开系统文件选择框（多选） |
| `list_files()` | 无 | `{ok, items[], output_dir}` | `@` 引用候选：最近生成文件 + 输出目录，含 `name/path/size/source` |
| `quit_app()` | 无 | `{ok}` | 退出程序 |

附件示例：

```js
// 图片：data 为纯 base64 或 data URL
await window.pywebview.api.send({
  text: '这张截图哪里有问题？',
  attachments: [{ type: 'image', data: base64 }],
});

// 文本文件：前端读取内容后传入，最多 4 个附件，超长截断到 32000 字符
await window.pywebview.api.send({
  text: '看看这个日志',
  attachments: [{ type: 'file', name: 'app.log', text: '...' }],
});
```

Agent 会把文本附件拼接在用户消息末尾（`【附件 名称】` + 代码块），图片按 `image_url` 传入，单轮最多 2 张。

前端输入约定：

- `/` 开头弹出命令菜单，回车执行（新对话、清空、历史、设置、模型、截图、区域、语音、文件、停止、帮助）。
- `@` 开头弹出文件候选（最近生成 + 输出目录），回车插入 `@绝对路径`；含空格路径插入 `@"..."`；末项“选择本地文件…”调用 `pick_files`。
- 拖入图片或文本文件会加入附件栏；其他类型提示改用 `/file`。

截图返回示例：

```json
{
  "ok": true,
  "base64": "iVBORw0KGgo...",
```

注意：截图宽度超过 1600px 会自动等比缩小；PNG 超过 4 MB 返回错误。

## 3. 设置字段

`settings_save(patch)` 支持的字段：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `base_url` | string | 模型接口地址，必须 `http(s)://`；默认 `https://api.deepseek.com` |
| `model` | string | 模型名，默认 `deepseek-flash` |
| `thinking` | string | `auto`（不发送 thinking 字段，由模型决定）/ `enabled`（强制思考）/ `disabled`（关闭） |
| `reasoning_effort` | string | `high` / `max` |
| `api_key` | string | 只在填写时更新；后端用 DPAPI 加密，不回传明文 |
| `output_dir` | string | 输出目录；会创建并保存绝对路径 |
| `theme` | string | `light` / `dark` / `system` |
| `accent` | string | `blue` / `green` / `violet` / `orange` |
| `language` | string | `zh` / `en` / `system`；后端会解析 system 为实际语言 |
| `profile` | object | `{name, avatar, color}`；`avatar` 为 orbit/spark/leaf/wave/cube/star，`color` 为 blue/green/violet/orange/slate；仅保存在本机 |
| `hotkey` | string | 例如 `ctrl+alt+space` |
| `voice_hotkey` | string | 例如 `ctrl+alt+v` |
| `timeout` | int | 请求超时秒数，15~600 |
| `max_tokens` | int | 最大输出 tokens，仅 `65536`（64K）或 `131072`（128K）；其他值按 96K 分界归档 |
| `notify_done` | boolean | 主窗口不在前台时，回答完成发托盘通知 |
| `show_api_errors` | boolean | 是否展示 API 错误详情 |
| `context_limit` | int | 上下文档位，仅 `131072`（128K）或 `1048576`（1M）；其他值按 600K 分界自动归档 |
| `context_compress` | boolean | 是否自动压缩：达到档位 50% 时把整个会话统一总结为摘要 |
| `update_repo` | string | GitHub `owner/repo`；留空不检查更新 |
| `update_auto_check` | boolean | 是否自动检查 GitHub Releases |
| `autostart` | boolean | 写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |
| `mode` | string | `safe` / `supervised` / `full`；旧值 `online` / `pro` 自动迁移为 `supervised` |
| `assistant_name` | string | 助手名称，最多 24 字；写入系统提示词并用于主界面问候 |
| `profile.avatar` | string | `default` / `custom`；上传头像时同时传 `profile.avatar_data`（data URL） |
| `profile.avatar_data` | string | 可选，PNG/JPG/WebP 的 data URL，最大 8MB；保存后裁为 256×256 PNG |

## 4. 事件协议

Python → 前端，统一格式：

```json
{"type": "事件名", "...": "字段"}
```

| 事件 | 字段 | 说明 |
| --- | --- | --- |
| `state` | `status`: `thinking` / `working` / `idle` / `error` | 当前运行状态 |
| `assistant_delta` | `id`, `text` | 流式文本增量 |
| `reasoning_delta` | `id`, `text` | 思考过程增量，前端显示为可折叠块 |
| `assistant_done` | `id`, `text`, `stopped?`, `network_error?` | 一段回复完成；`stopped=true` 表示用户停止或网络中断；`network_error=true` 表示已保留部分回答 |
| `tool_start` | `id`, `name`, `args` | 工具开始执行 |
| `tool_end` | `id`, `name`, `ok`, `summary`, `ms` | 工具结束 |
| `confirm_request` | `id`, `title`, `detail`, `command`, `tool` | 请求用户确认；前端弹框后调用 `confirm_reply` |
| `ask_request` | `id`, `question`, `options`, `allow_text` | 请求用户回答；前端在对话消息列内联卡片展示（居中、隐藏空态），回答后调用 `ask_reply`；新对话/清空界面会先停止当前 run 并移除卡片 |
| `notify` | `title`, `message` | 桌面通知/界面 toast |
| `error` | `message`, `hint?`, `detail?`, `status?` | 错误提示；`detail` 为服务端原始错误，`status` 为 HTTP 状态码 |
| `context` | `action`: `usage` / `compressing` / `compressed` / `compress_failed` / `compress_skipped` / `trimmed`；`session_id`、`used`、`limit`、`percent`、`threshold`、`before`、`after`、`manual`、`summarized_count?`、`preview?`、`message?` | 上下文压缩与实时占用状态；前端按 `session_id` 过滤非当前会话事件 |
| `update_available` | `info`: 更新检查结果 | 发现新版本，前端弹更新窗 |
| `update_progress` | `phase`: `download` / `install`, `done`, `total` | 更新下载/安装进度 |
| `update_failed` | `message` | 更新失败 |
| `history_cleared` | 无 | 全部对话历史已清空 |
| `settings_reset` | `state` | 设置已恢复默认，前端重新应用状态 |
| `voice_state` | `recording?`, `downloading?`, `percent?`, `ready?`, `busy?`, `empty?`, `error?` | 本地语音状态：录音开始/结束、模型下载进度、识别中、无内容 |
| `voice_partial` | `text` | 实时识别的临时文本，录音期间每约 1.4 秒更新一次 |
| `voice_level` | `level`, `bands?` | 麦克风电平 0~1 与 9 段频段能量，约 12 次/秒，用于声波频谱动画 |
| `voice_result` | `text` | 本地语音最终识别结果，前端替换临时文本 |
| `control_state` | `active`, `released?` | AI 是否正在控制电脑屏幕；`ui_act` 执行时开启，任务结束或按 ESC 时关闭 |
| `todo` | `items`: `[{text,status}]` | 待办清单更新 |
| `files` | `items`: `[{path,name,size}]` | 生成文件/截图入栏 |
| `error` | `message`, `hint?` | 可展示的错误 |
| `settings_changed` | `settings` | 设置保存后广播 |
| `run_end` | `session_id` | 本轮对话结束（无论成功/失败/停止） |

事件示例：

```json
{"type":"tool_start","id":"call_ab12","name":"ui_act","args":{"hwnd":123456,"path":"0.2.1","action":"click"}}
{"type":"tool_end","id":"call_ab12","name":"ui_act","ok":true,"summary":"已在「记事本」对「保存」执行 click","ms":180}
{"type":"confirm_request","id":"c9f3a1b2c3","title":"要在「记事本」上单击吗？","detail":"目标：保存（Button）","command":"0.2.1  click","tool":"ui_act"}
```

## 5. 区域框选子进程协议

主进程通过子进程拉起全屏遮罩，避免阻塞 WebView2：

```text
Nexus.exe --pick-region <输出JSON路径>
```

子进程行为：

- 成功：写 `{"left":305,"top":228,"right":820,"bottom":560,"width":515,"height":332}`。
- 取消：写 `{"cancelled": true}`。
- 坐标均为虚拟屏幕绝对坐标，可能为负数（多显示器在主屏左侧/上方时）。
- 主进程读取临时文件后立即删除；子进程超时 120 秒。

开发模式命令：

```text
python app/main.py --pick-region C:\path\to\out.json
```

## 6. 模型接口

`LLMClient` 使用 OpenAI 兼容格式：

```text
POST {base_url}/chat/completions
Authorization: Bearer <api_key>
Content-Type: application/json
Accept: text/event-stream
```

请求体关键字段：

```json
{
  "model": "deepseek-flash",
  "messages": [{"role": "user", "content": "你好"}],
  "stream": true,
  "temperature": 0.3,
  "max_tokens": 8192,
  "thinking": {"type": "enabled"},
  "reasoning_effort": "high",
  "tools": [{"type": "function", "function": {"name": "...", "description": "...", "parameters": {"type": "object", "properties": {}}}}],
  "tool_choice": "auto"
}
```

`max_tokens` 只有 65536（64K）/ 131072（128K）两档，请求时按所选档位发送；`reasoning_effort` 只在思考未关闭时发送。

弱网处理：连接错误、超时以及 HTTP 408/500/502/503/504 会按 0.8s、1.6s、3.2s 左右指数退避重试，最多 4 次尝试；重试期间通过 `notify` 事件提示。流式读取中途断网时，已收到的文本作为 `stopped=true` 的部分回答写入历史。

响应按 SSE 解析 `data:` 行；工具调用增量按 `index` 拼接 `id`、`name`、`arguments`，最终转成：
```json
{
  "text": "",
  "reasoning": "思考过程……",
  "tool_calls": [
    {"id": "call_...", "type": "function", "function": {"name": "sys_info", "arguments": "{}"}}
  ],
  "finish_reason": "tool_calls"
}
```

思考模式下发生工具调用时，Agent 会把 `reasoning` 作为 `reasoning_content` 放回 assistant 消息，随下一轮请求一起发送；否则 DeepSeek 会返回 400。

错误映射：

| HTTP | 提示 |
| --- | --- |
| 401 | 模型密钥无效或已过期 |
| 404 | 接口地址或模型名不正确 |
| 429 | 请求太频繁或额度不足 |
| 5xx | 已自动重试，仍失败时提示模型服务暂时不可用 |
| 其他 | 请求失败（状态码），附带响应体前 500 字 |

## 7. 联网接口

`web_search` / `web_fetch` 使用 DeepSeek Search / Fetch API，与聊天共用密钥。

| API | 方法与地址 | 请求体 |
| --- | --- | --- |
| Search | `POST https://api.deepseek.com/v1/tools/search` | `{"query": "...", "count": 5, "need_content": false}` |
| Fetch | `POST https://api.deepseek.com/v1/tools/fetch` | `{"url": "https://..."}` |

Search 返回 `results[]`，每项包含 `title`、`url`、`snippet`、`summary`、`content`、`site_name`、`date`、`authority`。Fetch 返回 `title`、`content`（Markdown）。

Nexus 侧限制：

- `web_fetch` 只接受 http/https，拒绝含用户名密码的 URL、localhost、127.0.0.1、::1、*.local。
- Search 默认 `count=5`，最多 10；正文默认不返回。
- Fetch 正文截断 12000 字。
- 按官方价格计费：Search/Fetch 每 1000 次成功请求 $0.75。

## 8. 本地数据接口

数据库为 SQLite，路径 `%APPDATA%\Nexus\nexus.db`。标题、消息正文、工具参数、文件路径、审计详情、定时任务等字段以 `enc:v1:<base64>`（AES-256-GCM）存储，读取接口返回解密后的明文；主密钥由 DPAPI 保护，保存在 `secret.key`。设置保存于加密文件 `config.dat`。表结构见 `docs/05-项目总文档.md` §5。

审计记录由 `Safety.audit(action, detail, ok)` 写入 `audit` 表，不通过前端接口修改。

## 9. 安全说明

- JS API 没有单独的鉴权，依赖“只在本机 WebView2 中运行”这一边界。
- 前端不接触 API Key 明文；设置页只提交新值，`settings_get` 不返回密钥。设置与历史数据均加密落盘。
- `open_path` / `reveal_path` 接受前端传入的路径；前端只使用历史记录中的文件路径。
- `capture_screen` 会把图片以 base64 返回前端，前端随 `send` 上传给模型；这是当前已知隐私风险，详见 README“已知风险”。
- `ask_reply` 只接受前端传入的 `id` 和文本答案，不能借此触发工具。
- `schedule_*` 接口只管理定时任务表；真正执行由 Python 调度线程完成，运行时不经过前端确认。
- `shell_exec` 不通过 JS API 暴露；只能由模型在监管模式（逐条确认）或全部下放模式下调用。
