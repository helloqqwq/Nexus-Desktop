# Nexus 开发规划

> Network & Expert Utility Assistant —— 面向普通桌面用户的本地优先桌面智能助手

## 1. 目标与定位

- 一句话：用户说一句话，Nexus 在**本机**替用户排查电脑问题、整理文件、写文档、做简易网页、看图排错。
- 不是开发者工具：不暴露 token、向量库、模型参数等术语；所有能力以"场景"呈现。
- 运行形态：Windows 桌面常驻程序（悬浮球 / 桌面宠物 + 快捷键唤起）。

## 2. 硬性约束

| 约束 | 落实方式 |
| --- | --- |
| 绿色免安装、用户不装运行环境 | Python 运行时随包分发（PyInstaller onedir），双击即用；数据放 `%APPDATA%\Nexus`，U 盘便携模式见 §5 |
| 低硬件开销 | 无本地大模型、无 GPU 依赖；界面复用系统 WebView2；空闲内存目标 < 120MB |
| 低配可用 | 精简工具链 + 流式输出 + 不做全局索引 |
| 可离线弱网 | 无网络时仍可执行诊断、读写文件、生成静态 HTML/文档；在线时增强为对话式 AI |
| 安全 | 命令白名单 + 危险操作二次确认 + 敏感凭据 DPAPI 加密 + 全量操作日志 |

## 3. 技术选型（已定）

- **后端：Python 3.11（仅标准库 + 内置 SQLite）**，理由：
  1. 本机已具备 Python / PyInstaller / pillow，可产出免安装绿色包，用户侧零依赖；
  2. HTTP/SSE、JSON、文件系统、进程诊断迭代快，可靠性高于手写 C++ 版。
- **前端：HTML/CSS/JS + 系统 WebView2**（`pywebview`，走 Evergreen Runtime，Win10/11 基本自带）。
- **通信：前后端统一消息协议（JSON）**，UI 通过 `window.pywebview.api` 调用内核。
- **不引入**：Electron（体积过大）、Node 运行时、任何需要用户安装的组件。

> 已排除方案：C++ + WebView2（体积最优，但 JSON/SSE/图片编码需全部手写，交付风险高）；Electron（>150MB，违背低开销目标）。

## 4. 范围划分

### MVP（本轮必须交付）
1. 悬浮球 / 宠物双形态，可拖拽、贴边、点击展开对话；全局热键唤起输入框
2. 对话窗口：流式回复、预设场景胶囊、消息重发/复制、代码块与文件卡片
3. 智能体工具层（对齐通用 Agent 工具语义）：`fs_read / fs_write / fs_edit / fs_list / fs_search / shell_run / todo_write / net_diag / proc_list / sys_info / service_list / app_open / screenshot_capture`
4. 网络故障排查：ping / DNS / 网卡 / IP / 路由 / 代理 / 端口占用，AI 翻译成大白话并给修复步骤；修复动作必须弹确认
5. 文件与文档：生成 md/txt/csv、单文件 HTML（内联 CSS/JS，双击可开）
6. 任务记录：会话、工具执行、生成文件三类历史，本地 SQLite
7. 设置：API 地址/模型/密钥（DPAPI 加密）、默认输出目录、开机自启、安全/监管/全部下放三级权限切换
8. 截图提问：框选或全屏截图 → 传给多模态模型
9. 绿色打包脚本 + 自测

### 后续（不在本轮）
- 本地小模型（llama.cpp 可选插件）、文档向量检索、多显示器 DPI 深度适配、自动更新。

## 5. 目录与数据

```
nexus\
  app\
    main.py              启动器
    core\                内核（无 UI 依赖）
      agent.py           对话编排 + 工具循环
      llm.py             OpenAI 兼容客户端（流式）
      tools\             工具实现与注册表
      diag.py            诊断命令白名单
      safety.py          确认策略 / 路径沙箱
      store.py           SQLite 历史
      config.py          配置与 DPAPI 密钥
    web\                 UI（index.html / css / js / assets）
  build\                构建脚本、启动器、NSIS 安装脚本
  docs\                  规划 / 设计 / 进度 / 日志
```

- 配置与数据：`%APPDATA%\Nexus\`（加密配置 `config.dat`、加密字段的 `nexus.db`、`secret.key`、`files\`）
- 便携模式：可执行文件同级存在 `portable.flag` 时，全部数据写入 `.\data\`
- 发行产物：`release\Nexus-Setup-<版本>.exe`、`release\Nexus-Portable-<版本>.zip`

## 6. 阶段路线

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| P0 | 内核骨架、配置/DPAPI、工具注册表、诊断白名单 | 工具可调用并落库 |
| P1 | WebView2 外壳、悬浮球/宠物、热键、聊天 UI、设置页 | 双击启动出球，热键唤起，流式对话正常 |
| P2 | 文件/文档/网页生成、故障排查全链路、确认弹窗、历史页 | 一句话生成 HTML 并双击打开；断网可完成 ping/DNS 排查 |
| P3 | 截图提问、打包、审计与收尾文档 | `dist\Nexus\Nexus.exe` 在无 Python 环境可运行 |

## 7. 风险与对策

| 风险 | 对策 |
| --- | --- |
| 用户机器缺少 WebView2 | 启动检测并提示一键安装（Evergreen Bootstrapper 链接） |
| 杀软误报 PyInstaller 产物 | 提供 onedir 包 + 说明；不写注册表、不驻留服务 |
| 模型 API 不稳定/欠费 | 失败重试 + 明确错误提示；离线诊断能力不依赖模型 |
| 危险命令误执行 | 执行层硬白名单 + 修复类动作强制 UI 确认 + 全量审计日志 |
| 截图涉及隐私 | 截图仅本地编码后按需上传，UI 明示；默认不落盘 |

## 8. 验收口径

- 冷启动 ≤ 2.5s（SSD），空闲内存 ≤ 120MB
- 断网时：诊断类场景 100% 可用；文件/网页生成可用
- 所有写文件动作有路径展示；所有系统修改动作有确认弹窗
- 无硬编码密钥；设置与历史加密落盘，API Key 为 DPAPI 密文
